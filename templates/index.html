Agent Pipeline

6 stages · sequential processing

  1. 1

    Document Reader

    Extracts text, headings, images, tables, and code blocks

  2. 2

    Accessibility Auditor

    Detects barriers: scanned pages, missing structure, unlabelled visuals

  3. 3

    Subject Interpreter

    Identifies code, DSA diagrams, Calculus notation, and lecture text across all supported subjects

  4. 4

    Explanation Agent

    Produces plain-language descriptions of visuals, code, and equations

  5. 5

    Study-Pack Agent

    Creates structured HTML, audio chapters, glossary, and lecture chunks

  6. 6

    Grounded Learning Agent

    Answers questions only from the processed lecture, with page citations
